
# AutFlow — Project Instructions

## Architecture
- Preserve the existing HTML, CSS and JavaScript architecture.
- Reuse the current Three.js and GSAP implementations.
- Never migrate frameworks without explicit approval.
- Avoid unnecessary dependencies.

## Design principles
- Editorial and industrial visual identity.
- Prioritize visual hierarchy over decoration.
- Prefer asymmetric compositions where appropriate.
- Avoid generic SaaS layouts and repetitive cards.
- Use gradients and glows sparingly.
- Respect the existing brand identity.

## Content
- Write natural Colombian Spanish.
- Sell concrete business outcomes, not technology buzzwords.
- Never fabricate clients, testimonials or performance metrics.
- Keep paragraphs concise and commercially relevant.

## Code quality
- Use semantic HTML.
- Maintain accessible keyboard navigation.
- Support reduced motion.
- Design mobile layouts deliberately.
- Keep CSS tokens centralized.
- Avoid duplicated components and conflicting styles.

## Working process
1. Inspect before editing.
2. Present the proposed changes.
3. Request permission for architectural changes.
4. Implement incrementally.
5. Test the affected functionality.
6. Report what was actually verified.

Never claim visual verification without
rendering the page in a browser.
